Bootstrap Utilities Example

This is an example of Bootstrap utilities. Utilities are helper classes that can be used to quickly style elements without writing custom CSS.

Text Centered

This text is centered using the "text-center" utility class.

Text Right Aligned

This text is right aligned using the "text-right" utility class.

Text Left Aligned

This text is left aligned using the "text-left" utility class.

Text Uppercase

This text is transformed to uppercase using the "text-uppercase" utility class.

Text Lowercase

This text is transformed to lowercase using the "text-lowercase" utility class.

Text Capitalized

This text is transformed to capitalized using the "text-capitalize" utility class

Muted Text

This text is muted using the "text-muted" utility class.

Primary Text

This text is styled with the primary color using the "text-primary" utility class

Success Text

This text is styled with the success color using the "text-success" utility class

This text is styled with the warning color using the "text-warning" utility class

Danger Text

Secondary Text

Dark Text

This text is styled with the dark color using the "text-dark" utility class

Body Text

This text is styled with the body color using the "text-body" utility class

Black 50% Text

This text is styled with 50% black color using the "text-black-50" utility class

White 50% Text

This text is styled with 50% white color using the "text-white-50" utility class

Reset Text

This text is reset to the default color using the "text-reset" utility class

No Wrap Text

This text will not wrap to the next line using the "text-nowrap" utility

Truncated Text

This text will be truncated with an ellipsis if it overflows the container using the "text-truncate" utility class. This is useful for preventing long text from breaking the layout.

Break Text

This text will break into multiple lines if it overflows the container using the "text-break" utility class. This is useful for ensuring that long text is fully visible without breaking the layout.

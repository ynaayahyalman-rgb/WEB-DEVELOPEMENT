Bootstrap Containers Example

This is an example of Bootstrap containers. Containers are used to wrap the site contents and provide a responsive fixed width container or a full width container, depending on the screen size.

Fixed Width Container

This container has a fixed width that adjusts based on the screen size.

Full Width Container

This container spans the entire width of the viewport, regardless of the screen size.
